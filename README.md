# discourse-chat-demo

A Discourse plugin that keeps a Chat channel feeling **alive** for demo sites. It uses a
Discourse AI agent to write a daily, news-aware mock conversation for a game community, then
drips those messages into a chat channel on a steady cadence — a Discord-style channel that
always has fresh activity.

> ⚠️ For **demo sites only**. The conversation is generated by AI and posted by seeded demo
> users — the participants are not real people. A disclaimer is posted in the channel on setup.

## How it works

1. **Daily** (`Jobs::ChatDemo::GenerateScript`, `every 1.day`): a `ScriptAgent` (a Discourse AI
   agent that owns the Google search tool) researches recent news about the configured game and
   writes a fresh conversation as ordered `username: message` lines. These replace the contents
   of the `chat_demo_messages` table in one transaction.
2. **Every minute** (`Jobs::ChatDemo::DispatchMessages`, `every 1.minute`): fans out single-post
   jobs spaced evenly across the minute (`chat_demo_messages_per_minute`, default 6 → one every
   ~10s). When the script is fully posted it replays from the top, so the channel never goes
   quiet between daily refreshes.
3. **Per message** (`Jobs::ChatDemo::PostMessage`): atomically claims the next unsent line
   (`FOR UPDATE SKIP LOCKED`) and posts it as the matching cast user, so concurrent jobs never
   post the same line twice.

The cast is a fixed roster of seeded demo users (see `lib/chat_demo/cast.rb`); the agent is
constrained to those usernames so every generated line maps to a real user.

## Requirements

- [Discourse Chat](https://github.com/discourse/discourse/tree/main/plugins/chat)
- [Discourse AI](https://github.com/discourse/discourse-ai) with a default LLM configured
  (`ai_default_llm_model`)
- *(optional, for real news)* Google Custom Search keys — `ai_google_custom_search_api_key` and
  `ai_google_custom_search_cx`. Without them the agent still generates plausible chatter from the
  model's own knowledge.

## Settings

| Setting | Default | Description |
| --- | --- | --- |
| `chat_demo_enabled` | `false` | Master switch. Turning it on seeds the cast + channel and generates the first script. |
| `chat_demo_game_name` | `Deep Rock Galactic` | The game the channel is themed around; drives the news search and tone. |
| `chat_demo_messages_per_minute` | `6` | How many messages to post each minute. |
| `chat_demo_script_lines` | `100` | How many lines the daily generator targets. The script replays once exhausted. |
